# C Program Foundations & Practice

A curated collection of core C programs, practice exercises, and logic-building solutions mastering arrays, strings, pointers, and memory mechanics during Month 1 of B.Tech CSE.

## 📌 Core Modules

* **Basics & Control Flow:** Standard I/O operations, conditional branching, and optimized loops.
* **Arrays & Strings:** Deep dives into string traversal, memory layouts, and essential `<string.h>` functions.
* **Pointers & Memory:** In-depth mechanics covering memory addresses, pointer arithmetic, and string re-initialization.
* **Logic & Practice:** Comprehensive exercises and mini-projects engineered to sharpen problem-solving skills.
